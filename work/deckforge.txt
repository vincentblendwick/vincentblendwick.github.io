CORRECTLY</p></div></div></div><div class="coxi4xh"><div class="cfzzbgl"><div class="c70s8lp"><p class="c1hh1zyv">CONTEXT</p></div><div class="c1tvjzxp"><p class="c1q4pcov">A template does not hold a brand. PowerPoint hands every user a surface and a set of handles, and the drift starts on the second deck: a headline nudged down two points so a sentence fits, a colour picked out of an older file, a margin set by eye. Nobody breaks the system deliberately. It erodes.</p><p class="c1q4pcov">So the slide stops being a surface someone arranges and becomes an artefact the brand definition compiles. One definition holds colour, type scale, grid and lockups. Sixty-three layouts read from it. No layout carries a value of its own, and type sizes are fixed — nothing scales to fit, because auto-fitting text is the reason deck families come apart. Each slide finds its own size, and after three editors the series is gone.</p><p class="cdfzawv">That decision is the whole system, and it is the one that failed quietly.</p><p class="c1q4pcov">Line spacing was expressed as a percentage — of the font’s line height, not of the type size, which is what the layouts had assumed. Inter Tight carries 1.21 em, a serif more like 1.30. Every box in the set was therefore around twelve percent too tight for what it was meant to hold, and six roles could not fit a single line of their own style. The text did not clip. It grew into its neighbour.</p><p class="c1q4pcov">Fixing the six visible cases would have been the wrong repair. Line spacing is now absolute: type size times factor, resolved before the file exists and independent of which font the recipient has installed. Every box holds its designed line count again, and not one box was enlarged. The price is real and worth stating — absolute spacing ignores font metrics, so a face with unusually tall ascenders will set tight. That is a visible error rather than a counted one, which makes it the better of the two.</p></div></div><div class="cfzzbgl"><div class="c70s8lp"><p class="c1hh1zyv">MY ROLE</p></div><div class="c1tvjzxp"><p class="c1q4pcov">Sole author. CORRECTLY</p></div></div></div><div class="ciih68a"><div class="c13fmhzw"><div class="c5sfa80"><p class="c1qejeld">CONTEXT</p></div><div class="cbxrp4q"><p class="cfc3f5i">A template does not hold a brand. PowerPoint hands every user a surface and a set of handles, and the drift starts on the second deck: a headline nudged down two points so a sentence fits, a colour picked out of an older file, a margin set by eye. Nobody breaks the system deliberately. It erodes.</p><p class="cfc3f5i">So the slide stops being a surface someone arranges and becomes an artefact the brand definition compiles. One definition holds colour, type scale, grid and lockups. Sixty-three layouts read from it. No layout carries a value of its own, and type sizes are fixed — nothing scales to fit, because auto-fitting text is the reason deck families come apart. Each slide finds its own size, and after three editors the series is gone.</p><p class="c1nfvdop">That decision is the whole system, and it is the one that failed quietly.</p><p class="cfc3f5i">Line spacing was expressed as a percentage — of the font’s line height, not of the type size, which is what the layouts had assumed. Inter Tight carries 1.21 em, a serif more like 1.30. Every box in the set was therefore around twelve percent too tight for what it was meant to hold, and six roles could not fit a single line of their own style. The text did not clip. It grew into its neighbour.</p><p class="cfc3f5i">Fixing the six visible cases would have been the wrong repair. Line spacing is now absolute: type size times factor, resolved before the file exists and independent of which font the recipient has installed. Every box holds its designed line count again, and not one box was enlarged. The price is real and worth stating — absolute spacing ignores font metrics, so a face with unusually tall ascenders will set tight. That is a visible error rather than a counted one, which makes it the better of the two.</p></div></div><div class="c13fmhzw"><div class="c5sfa80"><p class="c1qejeld">MY ROLE</p></div><div class="cbxrp4q"><p class="cfc3f5i">Sole author.
