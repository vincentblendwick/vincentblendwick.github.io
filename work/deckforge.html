SHIPPED — MASTER IN USE

Deckforge

Designing a slide master that carries a brand is straightforward. The one I built shipped clean, looked correct, and was wrong in 48 of its 115 text roles — every box measured against a line height that no real font produces. Nothing appeared broken, which is exactly why it would have survived. What the system is built around now is the measurement that catches that.

48 OF 115 TEXT ROLES WRONG

6 COULD NOT FIT A SINGLE LINE OF THEIR OWN STYLE

MEASURED CORRECTLY

CONTEXT

A template does not hold a brand. PowerPoint hands every user a surface and a set of handles, and the drift starts on the second deck: a headline nudged down two points so a sentence fits, a colour picked out of an older file, a margin set by eye. Nobody breaks the system deliberately. It erodes.

So the slide stops being a surface someone arranges and becomes an artefact the brand definition compiles. One definition holds colour, type scale, grid and lockups. Twenty-nine layouts read from it. No layout carries a value of its own, and type sizes are fixed — nothing scales to fit, because auto-fitting text is the reason deck families come apart. Each slide finds its own size, and after three editors the series is gone.

That decision is the whole system, and it is the one that failed quietly.

Line spacing was expressed as a percentage — of the font’s line height, not of the type size, which is what the layouts had assumed. Inter Tight carries 1.21 em, a serif more like 1.30. Every box in the set was therefore around twelve percent too tight for what it was meant to hold, and six roles could not fit a single line of their own style. The text did not clip. It grew into its neighbour.

Fixing the six visible cases would have been the wrong repair. Line spacing is now absolute: type size times factor, resolved before the file exists and independent of which font the recipient has installed. Every box holds its designed line count again, and not one box was enlarged. The price is real and worth stating — absolute spacing ignores font metrics, so a face with unusually tall ascenders will set tight. That is a visible error rather than a counted one, which makes it the better of the two.

The deck master, and monthly posts for LinkedIn with an X adaptation.

The client isn’t named here. Names, content and images are removed; the system underneath is the real one.

DECISIONS

Fix every type size and remove auto-fit entirely.

BECAUSE

Auto-fit lets each slide settle on its own size, and three editors later the family has no scale left. Fixed steps reverse the relationship: the text adapts to the system.

WHAT IT COSTS

A hard character budget per role, and that conversation with everyone who supplies content.

Express line spacing as an absolute value in points instead of a percentage.

BECAUSE

A percentage is a percentage of the font’s line height, which lives in a file the recipient may not have. The layouts were all measured as if it were the type size.

WHAT IT COSTS

The setting no longer adapts to the typeface, so a face with tall ascenders sets tighter than its own metrics would ask for.

Repair the cause rather than the six roles anyone could see.

BECAUSE

The boxes were never too small; the lines were too tall. Enlarging the visible six would have left the other forty-two wrong and hidden the reason.

WHAT IT COSTS

A larger change than the bug report asked for, and every measured budget had to be recomputed.

Keep the generator and the deck that consumes it in separate repositories.

BECAUSE

A master that can be edited while fixing a slide is not a master. The separation makes that impossible rather than discouraged.

WHAT IT COSTS

Two checkouts and a round trip whenever a real deck turns up a real layout problem.

RESULT

SCOPE

BUDGET

63 layouts, one master

A character count per role

Seven families, from the cover to the closing. Every layout opens as a real slide in PowerPoint, every text box keeps its fixed size.

Measured against the real font files, not estimated — and the build refuses content that exceeds it.
